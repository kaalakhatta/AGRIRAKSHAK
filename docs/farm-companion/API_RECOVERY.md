## Observed failure and free fallback

Production weather and mapped-soil POST routes returned HTTP 200 with a fictional MP point. All three market-price routes returned HTTP 503. The official Agmarknet monthly endpoint returned HTTP 400 with TOKEN_OR_CAPTCHA_REQUIRED. No documented anonymous token-refresh route was established, and no CAPTCHA/access control was bypassed. The official eNAM legacy/current requests also failed; data.gov.in's published API timed out and its XML download was unavailable during investigation.

[Mandi Price API documentation](https://mandi-api.vercel.app/docs) publishes free, keyless access, MP coverage, and a limit of 100 requests per 15 minutes per IP. Its [publisher repository](https://github.com/shrinivas-sn/mandi-api) describes government data.gov.in ingestion, the response envelope, and noncommercial attribution terms. [Raw ingest implementation](https://github.com/shrinivas-sn/mandi-api/blob/main/backend/scripts/ingest.js) maps the source min/max/modal prices without replacing them with estimates. Upstream government data is the [daily mandi-price resource](https://data.gov.in/resource/current-daily-price-various-commodities-various-markets-mandi). The existing INR/quintal price contract is preserved. No publisher implementation is copied into this MIT app; no new dependency, API key, account, card or payment is required.

The original monthly source remains first. Only when both periods fail does the server request the mirror's latest raw crop/state records. Never call its state-average history endpoint. Validate crop/state in metadata and every row, dates, finite positive prices, min/modal/max ordering, bounded rows/body and mirror fetch times. Retain separate market/variety/grade series and actual duplicate modal points. Future and older-than-30-day report dates do not render. Failed/invalid mirrors remain unavailable.

The mirror returns at most 200 records, so all fallback histories are explicitly partial. At verification its newest report date was **24 September 2026**, not today; soybean/gram also included September 23. Actual retrieved rows parsed into 141 soybean, 200 wheat and 148 gram series, including Sehore. The UI shows Older report, exact report dates, mirror update time separately from app retrieval time, community-mirror attribution and limited coverage. No current price guarantee, invented interpolation, local selling offer or comprehensive history is claimed. A stalled mirror eventually has no records inside the 30-day window; that stays visibly empty. Server cache/deduplication and one-minute failure cooldown remain; server/client budgets allow the free mirror to wake.

## Scanner startup

The configured production backend took approximately 34 seconds to wake during investigation, then its live/ready health checks and valid generated-image prediction returned HTTP 200. A malformed tiny test image caused a backend error; a correctly encoded 256px synthetic PNG succeeded. This is transport evidence, not disease/accuracy validation.

A new same-origin GET /api/model-status checks only the configured backend's /health/ready (45-second timeout), returning only ready/unavailable with no-store. Endpoint validation is shared with the upload proxy. Analyze leaf first shows startup progress and checks readiness; no image is sent unless ready. A failed startup gives an explicit wait/retry message, and cancellation blocks late upload. The existing crop/consent, neutral filename, size, uncertainty and unsupported-result checks remain. No automatic image retry, background keep-alive or fabricated prediction is added. Cold starts can still exceed the bounded wait and require a user retry.
