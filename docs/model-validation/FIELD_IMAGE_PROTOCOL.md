# Field-Image Evaluation Protocol

This is a PLANNED protocol for evaluating models on field images. It is not evidence of completed evaluation.

## Distinction
- **Controlled-background:** Lab/PlantVillage images with clear subjects and uniform backgrounds.
- **Field/Phone images:** Real-world photos with varying lighting, complex backgrounds, and varying resolutions.

## Consent and Privacy
- **Consent:** Required for any farmer/field photography.
- **Non-identifying:** Protocol dictates no faces, no precise GPS coordinates, no farmer names to be included in the evaluation dataset.

## Variables in Phone Images
- Lighting conditions
- Angle and distance from the subject
- Background complexity
- Resolution and image compression

## Methodology
- **Sample sizes:** Minimum sample sizes per class to be determined for statistical significance.
- **Comparison:** Paired controlled vs. field accuracy comparison.
- **Data handling:** Secure storage, no Git commits of raw evaluation data, deletion after evaluation completion.
- **Review:** Agronomist sign-off is required.
