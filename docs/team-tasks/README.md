# Independent teammate tasks

These assignments are intentionally isolated. Each contributor works in a separate directory and submits a pull request for the repository owner to review.

To begin, give an AI agent the repository URL and one of these task numbers:

- Task 1: dataset audit utility
- Task 2: literature review
- Task 3: disease-content framework
- Task 4: exhibition QA package

The agent must read the root `AGENTS.md` and the matching task brief before editing.
