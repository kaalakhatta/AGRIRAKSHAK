# Task 2: Literature review

## Ownership

- Branch: `docs/literature-review`
- Allowed path: `docs/research/**`
- Do not change any other path.

## Goal

Create a verifiable research foundation for the AgriRakshak report and exhibition defence.

## Deliverables

Create:

```text
docs/research/LITERATURE_REVIEW.md
docs/research/BIBLIOGRAPHY.md
docs/research/CLAIMS_REGISTER.md
```

Cover crop-disease CNN classification, MobileNet or EfficientNet, PlantVillage limitations, field-image generalization, class imbalance, conventional augmentation, synthetic augmentation, model calibration, and responsible use.

## Evidence requirements

- Use at least 10 credible sources.
- Prefer peer-reviewed papers, official datasets, and primary documentation.
- Open and verify every source before citing it.
- Include DOI or stable links where available.
- Record the exact project claim supported by each source.
- Separate reported findings from the contributor's interpretation.
- Identify presentation claims that require softer wording or stronger evidence.
- Do not copy long passages from sources.

## Claims register columns

Use a Markdown table with: claim ID, proposed claim, source, evidence strength, limitations, and recommended wording.

## Completion evidence

The pull request must summarize the search method, list any claims that could not be verified, and confirm that every link was opened.
